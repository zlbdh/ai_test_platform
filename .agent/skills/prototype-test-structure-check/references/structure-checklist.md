# Structure Checklist

## List Pages

- Search region
- Table region
- Pagination region
- Statistics region or toolbar
- Row actions

## Form Pages

- Group headings
- Field region
- Validation-message region
- Submit/cancel region

## Detail/Review Pages

- Header summary
- Basic information
- Related data
- Review/processing actions

## Dashboard Pages

- Metric cards
- Chart containers
- Time filters or refresh entry points
- Empty/no-data messages
