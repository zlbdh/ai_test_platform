# Requirement Signals

## 必抽信号

- 模块名称
- 页面名称
- 页面类型：列表 / 表单 / 详情 / 审核 / 看板 / 弹窗
- 角色
- 主流程
- 关键动作
- 状态集合
- 状态变化条件
- 关键字段
- 字段约束
- 异常分支
- 跨模块依赖

## 典型文档问题

- 只写“有审核”，没写审核通过/驳回后的状态与按钮。
- 只写“可编辑”，没写哪些字段可编辑、哪些只读。
- 只写“支持导出”，没写导出范围和条件。
- 总览有路由，模块文档没有页面承接。

## 输出最少要回答

- 测什么
- 先测哪些页面
- 哪些规则必须进入原型核查
- 哪些内容即使做了原型测试也仍然无法证明
